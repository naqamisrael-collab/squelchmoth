System requirements

What you need

  • Mac: macOS 11 Big Sur or newer, Intel or Apple Silicon (native build for each)
  • Windows: Windows 10 or 11, 64-bit
  • 200 MB of free disk space
  • Any Core Audio (Mac) or Windows Audio interface, or the built-in audio
  • Internet only for the optional Claude connection
Install

Two minutes

Mac

  1. Unzip the download for your Mac.
  2. Right-click Install Squelchmoth and choose Open, then Open again.
  3. It copies Squelchmoth into Applications and offers to open it.

Windows

  1. Unzip and double-click Squelchmoth-Setup.
  2. If Windows says it protected your PC, click More info › Run anyway.
  3. Next › I Agree › Install. Squelchmoth is in the Start menu.

Bought a key? Open Help › Licences and Upgrades and paste it.
